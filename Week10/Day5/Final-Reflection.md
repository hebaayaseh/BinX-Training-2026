# 10-Week Program — Final Reflection

Completing the 10-week BinX Tech training program gave me practical experience in backend development and helped me understand how a project develops from individual exercises into a complete backend system.

During the program, I worked with C#, ASP.NET Core, Entity Framework Core, MySQL, authentication and authorization, testing, Redis caching, API documentation, and CI. Building and improving CardioTrack helped me connect the concepts I learned with real implementation problems.

One of the most valuable parts of the training was working on performance and testing. I learned that performance problems should be investigated using actual queries and measurements instead of assumptions. I also learned how testing can reveal security and infrastructure issues that may not appear during normal development.

The program also improved my ability to work with Git and GitHub, document my work, explain technical decisions, and present a backend project clearly.

I still have areas that I want to improve, especially writing more comprehensive tests, gaining more experience with deployment and production environments, and continuing to improve my system design skills.

Overall, the 10 weeks gave me a stronger foundation in backend development and more confidence in working on real software projects. I am leaving the program with practical experience that I can continue building on in my future backend career.
