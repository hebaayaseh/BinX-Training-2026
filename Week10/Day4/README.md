## 3. Live API Demo

The live demo was performed using Postman.

### Demo Flow

1. Login and obtain a JWT token.
2. Access a protected endpoint.
3. Retrieve patient data.
4. Demonstrate filtering, sorting, and pagination.
5. Show the API response.
6. Explain the relevant backend implementation.
