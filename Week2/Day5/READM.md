# MyFirstApi

## Overview
This project is a simple ASP.NET Core Web API created for learning purposes. It demonstrates both Controllers and Minimal APIs 
and demonstrates Middleware and Dependency Injection in ASP.NET core web API.

## Features
- GET all items
- GET item by ID
- Controller endpoints
- Minimal API endpoints
- Swagger support
- Custom request logging middleware
- Dependency Injection with a service

## Endpoints

### Controller
- GET /api/items
- GET /api/items/{id}
- Get /item/dependency-injection

### Minimal API
- GET /minimal/items
- GET /minimal/items/{id}

## Testing
The API was tested using Swagger and Postman.
