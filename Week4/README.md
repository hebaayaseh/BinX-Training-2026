# Week 4 – Authentication, Identity & Input Validation

## Overview

Week 4 focused on securing the REST API with authentication, authorization, input validation, and API security. The training covered ASP.NET Core Identity, JWT authentication, role-based access control, FluentValidation, and security hardening through practical hands-on tasks.

## Learning Outcomes

By the end of this week, I was able to:

* Set up ASP.NET Core Identity for user management and secure password storage.
* Implement user registration and login functionality.
* Create and validate JWT access tokens.
* Configure JWT Bearer Authentication and token expiry.
* Protect API endpoints using the `[Authorize]` attribute.
* Implement role-based access control using `User` and `Admin` roles.
* Apply claims-based and policy-based authorization.
* Validate API requests using FluentValidation.
* Return structured validation errors for invalid requests.
* Configure rate limiting to protect sensitive endpoints.
* Configure CORS and basic security headers.
* Understand how Entity Framework Core helps prevent SQL injection through parameterized queries.
* Test authentication, authorization, and validation using Postman.
